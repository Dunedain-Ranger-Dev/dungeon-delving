# Dungeon Delving
A Minecraft mod (NeoForge 1.21.1) for repeatable, procedurally generated dungeon runs: dive in, survive, and bring the loot home to grow stronger. Built as the core of a magic-focused modpack.

Building dungeon pieces: see [BUILDING.md](BUILDING.md).

It works on its own. Its sister mods, each in its own repository: [Professions and Skills](https://github.com/Dunedain-Ranger-Dev/professions-and-skills) (skill trees, forging, races and classes; when both are installed, dungeon mobs have tier levels and dungeon metals feed its higher workshops), [Kingdom Sim](https://github.com/Dunedain-Ranger-Dev/kingdom-sim) (the realm, whose monster nations are this mod's factions) and [Deep Mines](https://github.com/Dunedain-Ranger-Dev/deep-mines) (a resettable mining dimension). Check them out next to this one to build and test them together; the whole pack runs from the [pack repository](https://github.com/Dunedain-Ranger-Dev/dungeon-delving-pack)'s dev project.
